# FIFA Data Analysis using SQL

## Project Overview

This project focuses on analyzing FIFA football data using SQL.

The project uses SQL queries to explore player, team, match, and performance-related data and extract useful insights from the dataset.

## Tools Used

* MySQL
* DBeaver
* SQL

## SQL Concepts Used

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* HAVING
* Aggregate Functions
* JOIN
* Subqueries

## Project Analysis

The project includes SQL queries to analyze FIFA data and answer different business and analytical questions, such as:

* Analyzing player statistics
* Comparing team performance
* Finding top-performing players
* Analyzing match-related data
* Using aggregate functions for statistical analysis
* Using JOINs to combine data from multiple tables

## Key Learning

This project helped me improve my SQL skills and understand how SQL can be used to analyze real-world sports datasets and generate meaningful insights.
